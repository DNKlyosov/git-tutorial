# 🚀 Интерактивный учебник по Git

**Текущая версия: v1.0.0**

Добро пожаловать в интерактивный учебник по Git! Этот проект создан для того, чтобы помочь новичкам освоить систему контроля версий Git не только в теории, но и на практике.

Вместо скучных лекций вы будете вводить реальные команды в симуляторе терминала и наглядно видеть, как файлы перемещаются между рабочей директорией, индексом (Staging Area) и удаленным репозиторием.

### 🌐 Живая демонстрация

Попробовать учебник в действии можно прямо сейчас в браузере:
👉 **[https://dnklyosov.github.io/git-tutorial/](https://dnklyosov.github.io/git-tutorial/)**

### ✨ Что внутри?

* **21 подробный урок**: от первой настройки (`git config`) и `git init` до работы с хуками, `reflog` и настройки VS Code.
* **Интерактивный терминал**: работающая симуляция команд Git прямо на странице.
* **Визуализация**: наглядное отображение того, как файлы переходят из Working Directory в Staging Area и Local Repository, а затем улетают на GitHub.
* **Ссылки на Pro Git**: каждое упоминание команды ведет на соответствующий раздел официальной книги по Git.
* **Интеграция с VS Code**: бонусный урок о том, как делать то же самое с помощью графического интерфейса.

### 🛠️ Технологии

Проект написан на чистом **HTML, CSS и JavaScript** (Vanilla JS). Без сложных сборщиков, фреймворков и зависимостей. Легко читается, легко модифицируется.

### 💻 Как запустить локально?

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/DNKlyosov/git-tutorial.git
   ```

2. Перейдите в папку проекта.

3. Откройте файл index.html в любом браузере (или используйте расширение Live Server в VS Code).
