Незаконченная работа, а срочно нужна другая задача? Спрячем изменения в stash и вернём их, когда освободимся.

Урок 10. Временное убежище

NOTE Зачем это нужно?

Незаконченную работу не хочется коммитить, а переключаться на другую задачу нужно сейчас. git stash временно убирает правки, чтобы рабочая директория стала чистой.

Зачем прятать изменения

Представьте: вы правите файл, ещё не готовы к коммиту, и тут приходит срочная задача. Коммитить черновик не хочется — история станет грязной.

Переключаться на другую ветку с «грязной» директорией тоже неудобно и рискованно. Для такого случая есть git stash.

Команда забирает незаконченные изменения в отдельное хранилище и оставляет рабочую директорию чистой — как будто вы ничего не трогали.

Как вернуть спрятанное

Когда срочная задача сделана, выполните git stash pop: изменения вернутся, а запись из stash исчезнет. Commit при этом не создаётся — вы просто продолжаете с того же места.

В этом уроке файл сначала попадает в индекс, поэтому git stash уносит его прямо из Staging Area, а git stash pop возвращает обратно в индекс.

  1. touch wip.txt — создать файл с начатой работой.
  2. git add wip.txt — подготовить его к коммиту.
  3. git stash — спрятать: индекс снова чистый.
  4. git stash pop — вернуть работу из stash.

В панели справа появился отдельный блок Stash: после git stash файл исчезнет из Staging и окажется там, а после git stash pop вернётся в индекс.
