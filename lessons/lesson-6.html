Слияние веток

Возвращаемся в главную ветку и вливаем в неё изменения из feature командой git merge.

Как объединить работу

Когда эксперимент в ветке feature удался, его изменения переносят в основную ветку. Сначала переключаются на master, затем выполняют git merge feature.

Git создаёт коммит слияния и добавляет его в историю: изменения из ветки становятся частью главной линии.

  1. git checkout master — вернуться в главную ветку.
  2. git merge feature — влить изменения из feature.

После слияния в Local Repository появится карточка коммита с меткой «merge», а в терминале — сообщение Merge made by the 'ort' strategy.
