Урок 2. Добавление файлов

NOTE Зачем это нужно?

Git не начинает следить за файлом сам: новый файл остаётся «неотслеживаемым», пока вы не добавите его в индекс. Индекс — черновик будущего коммита, и в нём легко проверить, что именно попадёт в историю.

Четыре шага от файла до индекса

В проекте уже есть index.html — главная страница. Теперь добавим новую страницу about.html («О нас») и проследим, как Git начнёт за ней следить.

Git замечает новые файлы, но не отслеживает их, пока вы не добавите их в индекс. Пройдём короткую цепочку: создать файл, посмотреть статус, добавить в индекс и убедиться, что он готов к коммиту.

  1. touch about.html — создать страницу «О нас». Git покажет её как untracked.
  2. git status — проверить, что файл попал в раздел Untracked files.
  3. git add about.html — перенести файл в индекс (staging area).
  4. git status — снова проверить статус: файл теперь в Changes to be committed.

Если репозиторий не инициализирован, терминал предупредит: «Репозиторий не инициализирован! Вернитесь в Урок 1 или введите git init». Шаги засчитываются строго по порядку — второй git status сработает только после git add.
