Видео и архивы плохо уживаются с Git, а иногда проект зависит от репозитория, который живёт отдельно. Для этого есть LFS и подмодули.

Урок 18. Большие файлы и подмодули

NOTE Зачем это нужно?

Видео и архивы раздувают репозиторий, а чужой проект хочется подключить целиком. Для больших файлов есть Git LFS, для внешних репозиториев — подмодули.

Почему бинарники — проблема

Git хранит каждый файл целиком, как blob (урок 16). Для текста это выгодно: похожие версии хорошо сжимаются. Но видео, архивы и картинки так не жмутся — каждая правка файла на 500 МБ создаёт в истории ещё один объект на 500 МБ.

Репозиторий быстро разрастается, клонирование и отправка замедляются, а git diff по такому файлу бесполезен. Хуже всего, что старые версии остаются навсегда: история неизменяема, и «удалить» файл из прошлых коммитов нельзя.

Git LFS

Large File Storage решает это так: в репозитории остаётся указатель на файл, а сам файл лежит на отдельном LFS-сервере. История хранит крошечные текстовые заглушки, а тяжёлые данные лежат рядом.

Подключается одной командой: git lfs track "*.mp4". Она записывает правило в .gitattributes, и дальше все подходящие файлы автоматически уходят в LFS. Для этого нужен сервер, поддерживающий LFS, — GitHub и GitLab это умеют. 

$ git lfs track "*.mp4"
[Учебная подсказка]: Файл добавлен в LFS-хранилище

Подмодули

Подмодуль — это другой репозиторий, подключённый внутрь вашего. Git хранит не его код, а ссылку на конкретный коммит чужого репозитория. Удобно, когда проект зависит от общей библиотеки, которую ведут отдельно.

Ссылка запоминается точная — на конкретный коммит, — поэтому подмодуль не «уплывёт» вслед за чужой веткой. При клонировании проекта содержимое подмодулей не скачивается само: нужен git submodule update --init. 

$ git submodule add https://github.com/user/library.git
[Учебная подсказка]: Подмодуль успешно подключен.

Список подмодулей лежит в файле .gitmodules, и он, в отличие от содержимого самих подмодулей, коммитится в проект.

Когда что использовать

LFS — для больших бинарных файлов внутри вашего репозитория. Подмодули — когда часть проекта (библиотека, общий набор стилей) живёт в отдельном репозитории и нужна не всем.

Оба механизма добавляют сложности. Прежде чем тянуть в Git видео или чужой репозиторий, подумайте: может, хватит .gitignore и внешнего хранилища файлов. В этом уроке git lfs track и git submodule add — заглушки: они показывают сообщение, но панели не меняют.
