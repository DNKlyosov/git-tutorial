Урок 4. Связь с GitHub

NOTE Зачем это нужно?

Пока проект не связан с удалённым репозиторием, коммиты живут только на вашем компьютере: их не видит команда и не сохранит резервная копия. GitHub даёт общую копию, с которой работают все участники.

Связь, отправка и получение

GitHub хранит копию проекта в интернете — для резервной копии, совместной работы и публикации. Связь с удалённым репозиторием называют origin.

git remote add запоминает адрес, git push отправляет коммиты, git fetch скачивает изменения без применения, а git pull скачивает и сразу применяет их.

  1. git remote add origin https://github.com/user/project.git — связать проект с GitHub.
  2. git push -u origin master — отправить коммиты.
  3. Коллега пушит новый коммит — движок напечатает учебную подсказку.
  4. git pull origin master — скачать и применить изменения.

NOTE master или main

В нашем тренажёре используется историческое название главной ветки — master. В современных версиях Git и на GitHub по умолчанию используется название main. Если вы работаете в реальном терминале, и Git ругается, что ветки master не существует, попробуйте заменить в команде master на main.

После git pull в Local Repository появится новый коммит коллеги, а в терминале — сообщение о том, что файлы обновлены.
